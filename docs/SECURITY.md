# AegisOps Security Architecture & Controls

> **Status:** All base and Showcase security controls implemented and verified through Showcase Phase 07 (`docs/evidence/showcase-test-gate.txt`, `65/65` pytest passing including Playwright Chromium E2E).

## Security Boundaries
1. **Privacy Boundary & Zero-Persistence Playground (`backend/app/privacy/scrubber.py`, `backend/app/api/showcase.py`)**: Earliest-boundary scrubbing strips SSNs, healthcare Member IDs/MBIs/MRNs, emails, phone numbers, DOBs, Bearer/JWT tokens, IPv4 addresses, and contextual patient/member names before logs, queues, embeddings, Ollama, Langfuse, or Ragas. Fail-closed fallback retains only a minimal safe incident record on sanitizer failure. `POST /api/v1/showcase/privacy/preview` runs identically in memory (`<= 8 KiB` payload limit -> `413`, Redis `30 req/60s` rate limit -> `429`), never logs or persists pasted text, and explicitly discloses regex limits (such as unlabeled prose names). Does not imply HIPAA certification or zero-leakage guarantees.
2. **Webhook & Business Probe SSRF Guards (`webhooks.py`, `probes.py`)**: Alertmanager webhook requires HMAC-SHA256 or Bearer authentication, bounded payload size (`256 KiB`), Redis-backed rate limiting, and rejects arbitrary URLs (`_contains_forbidden_fetch_directive`). Business Transaction Probes restrict targets strictly to the 4 allowlisted demo services; arbitrary URLs fail with HTTP `400`.
3. **LLM Prompt-Injection & Markdown Upload Guards (`diagnosis.py`, `engine.py`, `runbooks.py`)**: Telemetry and runbook bodies are delimited inside XML tags (`<untrusted_telemetry>`, `<retrieved_runbook_data>`); Ollama cannot return shell commands, namespaces, or arbitrary image tags. Uploaded `.md` files (`<= 64 KiB`, strict UTF-8, `operator+`) reject path traversal, `<script>` / `javascript:` / inline event handlers, unknown `permitted_playbook_id` values, and `risk_tier` downgrades (`400`); uploads are indexed strictly as reference knowledge under `PLAYBOOK_REGISTRY`. Stateful database failover (`RB-011`) always resolves to `REFUSE_AND_ESCALATE`.
4. **Kubernetes Least Privilege & Data Plane Isolation (`executor.py`, `controls.py`)**: Explicit kubeconfig context allowlist (`kind-aegisops-local`), Terraform-managed namespace-scoped `Role` (`aegisops-healthcare` only via `aegisops-remediator`), and strict replica/memory/image bounds. `Restore Demo Baseline` operates solely on declared demo deployments inside `aegisops-healthcare` while preserving audit/incident history. Control-plane PostgreSQL/Redis sit isolated in Docker Compose.
5. **Identity, RBAC, Step-Up TOTP & Safe Exports (`oidc.py`, `totp.py`, `postmortem.py`)**: Visitor Mode exposes strictly read-only public showcase routes (`visitor+`). Live operational queues, prompt inspection, and `.md`/`.pdf` postmortem downloads require `viewer+`; scenarios, probes, runbook uploads, pause toggle, and baseline resets require `operator+` + CSRF; high-risk approvals strictly enforce `approver` + Fernet-encrypted `pyotp` TOTP (`valid_window=1`, atomic replay lock, UID/`resourceVersion` drift check). Postmortem `.md`/`.pdf` exports neutralize embedded HTML/scripts and exclude TOTP seeds, OTP codes, session cookies, and tokens while rendering PDFs purely locally with zero remote fetches.
